## 2. Полный список сетей и выводов

| Сеть | Выводы | Назначение / замечание для PCB |
|---|---|---|
| `/AOUT` | A1.3 | Отдельный измерительный выход сенсорного модуля. Не соединять с DOUT, Earth или VCC. Вывести только в удобную область измерительного доступа, не добавлять скрытую подтяжку. |
| `/VCC` | A1.1, C3.1, DA1.8, HL2.2, R1.1, R3.2, R4.2, XS1.1 | Основная шина +5 В. Разветвление к DA1, сенсорному разъёму и нагрузкам. Ширину магистралей определить после измерения A1/HA1 и полного режима тревоги. |
| `Earth` | A1.4, C1.2, C2.2, DA1.1, HL1.1, VT1.3, XS1.2 | Общий провод E3. На B.Cu стремиться к непрерывному полигону. Не допускать узких возвратных горлышек между DA1/LED и входным сигналом A1. |
| `Net-(A1-Pin_2)` | A1.2, R1.2, R2.1 | Цифровой выход DOUT от A1 с подтяжкой R1 и входом в базовую цепь VT1 через R2. Не путать с AOUT. Выходной тип/ток DOUT конкретной V2 проверить на образце. |
| `Net-(DA1-CONT)` | C2.1, DA1.5 | Развязка управляющего входа CONT на C2.1. C2.2 идёт на Earth. Ставить C2 рядом с DA1.5 и DA1.1. |
| `Net-(DA1-DISCH)` | DA1.7, R4.1, R5.1 | Узел DISCH времязадающей цепи. Разместить R4/R5 компактно у DA1.7. Не вести рядом с A1.2/A1.3 дольше необходимого. |
| `Net-(DA1-OUT)` | DA1.3, R6.1, VD1.2 | Выход таймера. Делится на ветви HL1 через R6 и звуковую цепь через анод VD1. Нагрузку DA1 оценивать совместно, а не по отдельным ветвям. |
| `Net-(DA1-THRES)` | C1.1, DA1.2, DA1.6, R5.2 | Объединённый TRIG/THRES и времязадающий конденсатор C1. Это высокоомный времязадающий узел. Минимизировать длину и площадь петли, удалить от выхода DA1 и силовых возвратов. |
| `Net-(DA1-~{RST})` | DA1.4, R3.1, VT1.2 | Активный низкий RESET. VT1 collector и R3 образуют узел сброса. Разместить VT1 близко к DA1.4, R3.1 — коротко к /VCC. |
| `Net-(HA1-Pin_1)` | HA1.1, VD1.1 | Одна сторона HA1 соединена с катодом VD1. Полярность и физический вывод HA1 проверить по маркировке OEM2690R на реальном излучателе. Не переставлять выводы по типовой схеме зуммера. |
| `Net-(HA1-Pin_2)` | HA1.2, R7.1, SA1.1 | Вторая сторона HA1, узел R7.1 и контакт SA1.1. Это отдельная коммутируемая ветвь. Разместить R7/SA1/HA1 компактно у акустической зоны. |
| `Net-(HL1-A)` | HL1.2, R6.2 | Анод HL1 через R6 от DA1.OUT. Катод HL1.1 идёт на Earth. Короткий путь от R6 к LED и доступ к индикаторному окну. |
| `Net-(HL2-K)` | HL2.1, R7.2 | Катод HL2 соединён с R7.2. Анод HL2.2 идёт на /VCC. Это не путать с HL1, у которого анодная ветвь питается от DA1.OUT. |
| `Net-(SA1-B)` | C3.2, SA1.2 | Отдельная изолированная сеть. По утверждённому netlist она не соединена с Earth, VCC или другими сетями. Не добавлять GND-полигонный контакт, переходное отверстие или монтажную перемычку в этот узел. |

## 3. Выводы компонентов, важные для ориентации footprint

| Компонент | Pad / pin map из утверждённой E3 | Примечание |
|---|---|---|
| A1 | 1=VCC, 2=DOUT, 3=AOUT, 4=GND | Порядок физического Molex pin 1 проверить на V2 и жгуте. |
| DA1 | 1=GND, 2=TRIG, 3=OUT, 4=RESET, 5=CONT, 6=THRES, 7=DISCH, 8=VCC | PDIP-8 NE555P имеет тот же стандартный pin numbering, но symbol/footprint parity проверить в KiCad. |
| VT1 | 1=B, 2=C, 3=E | КТ3102Б — металлостеклянный тип. Не использовать старый KT-26/TO-92 footprint. |
| VD1 | 1=K, 2=A | В netlist pin 1 — катод в HA1.1, pin 2 — анод в DA1.OUT. |
| HA1 | 1=Pin_1, 2=Pin_2 | Полярность физической детали проверить. Электрические сети выше важнее предположения «типового зуммера». |
| SA1 | 1=A, 2=B | Двухконтактная E3-коммутация. Кандидат NKK AS11AP требует pad1→terminal1, pad2→terminal3. |

## 4. Запрещённые изменения при трассировке

1. Не объединять `/AOUT` с `Net-(A1-Pin_2)`.
2. Не объединять `Net-(SA1-B)` с `Earth` или `/VCC`.
3. Не добавлять U2, P1, RHYS, VT2, R8 или R9 — их нет в утверждённой E3.
4. Не переносить старую карту сетей с платы `cad/kicad/gazo_analizator_preliminary.kicad_pcb`.
5. Не менять нумерацию A1/DA1/VT1/HA1/SA1 ради удобства footprint.
6. Не считать успешное совпадение netlist доказательством корректности физических footprints или непрерывности меди.

## 5. Автоматическая проверка

Запуск из корня репозитория:

```fish
python3 cad/scripts/verify_e3_netlist.py
```

Ожидаемый результат:

- PASS по 47 выводам;
- PASS по отдельному A1.3 /AOUT;
- PASS по изолированной паре C3.2/SA1.2.

Проверка сравнивает XML-netlist с зафиксированным эталоном. Она не проверяет footprint pin map, copper routing или DRC.
