# Предварительные графические листы

SVG-файлы в `exports` генерируются скриптом `generate_preliminary_drawings.py` из актуальной компоновки KiCad и текущих размеров FreeCAD-концепта.

- `PP_preliminary.svg` — предварительный чертёж расположения компонентов на PCB 72×50 мм.
- `VO_preliminary.svg` — концепт наружных видов корпуса 120×78×42 мм.
- `SB_preliminary_exploded.svg` — компоновочная взрыв-схема для обсуждения сборки.
- `electrical_topology_preliminary.svg` — функциональная топология к будущей Э3, не официальная принципиальная схема.
- `drawing_manifest.json` — статус и ограничения графических материалов.

SVG и `drawing_manifest.json` являются версионируемыми исходными графическими материалами и остаются в Git. Растровые PNG-превью формируются только в CAD workflow из этих SVG, помещаются в `cad/output/drawing_previews/` и включаются в CI-артефакт `gazo-preliminary-kicad`. PNG-превью намеренно не хранятся в Git. Это правило относится только к `cad/drawings/exports/` и не затрагивает иллюстрации РПЗ в `docs/figures/`.

Все листы содержат предупреждение PRELIMINARY / НЕ ДЛЯ ИЗГОТОВЛЕНИЯ. Штамп является временной разметкой и не должен восприниматься как точное воспроизведение утверждённой основной надписи МАИ. Перед выпуском нужно согласовать код проекта, форму штампа, позиционные обозначения, масштабы и формат листов.

Никакой из этих SVG не доказывает электрическую готовность платы. Э3, ПЭ3, routed PCB и сборочный чертёж с утверждённой спецификацией должны быть согласованы друг с другом.
