# Политика веток проекта gazo_analizator

**Зафиксировано:** 25.10.2026.  
**Единая основная рабочая ветка:** `analysis/vendor-behavioral-reconciliation`.

## Правило работы

Вся дальнейшая разработка, исправления, проверки, контрольные точки и журналирование ведутся только в `analysis/vendor-behavioral-reconciliation`. Не создавать параллельные линии исправлений и не продолжать работу в исторических ветках. Если обнаружен полезный незакоммиченный или уникальный результат старой ветки, сначала явно перенести и проверить его в основной рабочей ветке, затем пометить старую ветку как superseded.

Эта договорённость назначает **основную рабочую ветку**. Она сама по себе не меняет настройку GitHub Default branch. До изменения этой настройки GitHub продолжит отображать `main` как default branch. PR №4 должен быть направлен в `main`, оставаясь черновым до проверки интеграции и принятия решения о слиянии.

## Обязательные правила

1. Перед следующим изменением прочитать текущие `README.md`, `docs/engineering_log_2026-10-25.md`, `requirements/verification_matrix.md` и соответствующий checkpoint.
2. После каждого существенного изменения делать отдельный небольшой коммит, обновлять журнал и записывать статус CI. Не отмечать непроверенное действие как PASS.
3. Считать результат завершённым только в пределах явно прошедшей проверки. Успех SPICE не доказывает правильность реального MQ-4, точное поведение КР1006ВИ1, ток полного изделия или безопасность устройства.
4. Ничего не удалять из исторических веток. Маркер superseded означает «не продолжать и не интегрировать самостоятельно», а не «удалить историю».
5. Не сливать PR автоматически. Перед интеграцией в `main` сверить текущий HEAD, результаты CI, матрицу требований и состояние всех блокеров.

## Последняя проверенная опора

На последней проверке после согласования статусных баннеров и абсолютных ссылок README сравнение показывает 125 коммитов в основной рабочей ветке сверх общей базы и 3 коммита только в `main`. Эти три коммита касаются только статусного баннера README и абсолютных ссылок, а не функционального кода. PR №4 перенаправлен на `main`; GitHub сообщил `mergeable=true`, но CI на актуальном HEAD должен пройти до принятия решения о слиянии. Ветка `audit/russian-figures-spice-consistency` является историческим предком основной линии; `fix/russian-figures-electrical-audit` имела 14 уникальных коммитов относительно общей базы. Полезные идеи статических проверок перенесены в адаптированный regression test, поскольку прежний тест требовал изображать P1-потенциометр в рисунке, который намеренно представляет фиксированный SPICE-делитель.

PR №2 и PR №3 закрыты как superseded. Их ветки сохранены и в README содержат явный запрет на дальнейшую разработку. PR №4 — единственный открытый интеграционный PR и остаётся Draft.

Этот реестр служит источником истины по статусу веток и предотвращает параллельную разработку.
