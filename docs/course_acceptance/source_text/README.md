# Источники и полнотекстовый доступ

Полные оригиналы PDF предоставлены пользователем и находятся в его файловой библиотеке. В данный каталог помещены аналитические конспекты критериев и ссылки на страницы оригиналов. Полнотекстовые извлечения доступны в библиотеке ChatGPT, но не были загружены в Git в этой ревизии. Если Codex нуждается в более глубоком анализе полного текста, использовать файлы, названные ниже, из локальной библиотеки пользователя или запросить у пользователя копию в рабочем каталоге.

- ОКТ РЭС 98.pdf — МАИ, «Основы конструирования и технологии РЭС», 1998, 128 страниц.
- УП Проектирование РЭС КП и ДП-2007г _.pdf — МАИ, «Проектирование РЭС», 2007, 96 страниц.
- МУ оформлен КП и ДП 92г_.pdf — МАИ, методические указания по оформлению, 1992.

Не делать вид, что полные PDF лежат в этом каталоге. Использовать конспекты рядом и сверяться с оригиналами по точным пунктам и страницам, когда они доступны.
