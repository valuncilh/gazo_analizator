# Источники и полнотекстовый доступ

Полные поисковые текстовые извлечения из трёх предоставленных пользователем PDF сохранены в этом каталоге. В них сохранены текст и доступные метки страниц. Они не являются копией исходной графической вёрстки. При чтении таблиц, иллюстраций, формул, бланков и неоднозначного текста обращаться к оригинальному PDF пользователя.

- ОКТ РЭС 98.pdf — МАИ, «Основы конструирования и технологии РЭС», 1998, 128 страниц.
- УП Проектирование РЭС КП и ДП-2007г _.pdf — МАИ, «Проектирование РЭС», 2007, 96 страниц.
- МУ оформлен КП и ДП 92г_.pdf — МАИ, методические указания по оформлению, 1992.

Полные исходные PDF лежат в личной библиотеке пользователя. Для анализа текста Codex использует эти извлечения, а для анализа графики и спорных фрагментов — исходные PDF, когда они доступны.
