# Методическая база курсового проекта

См. CODEX_RULES.md. Эта папка содержит конспекты критериев МАИ 1998, 2007 и 1992 годов. Codex обязан использовать их при начале сессии, переходе этапа и приёмке.

Пользователь установил условную постановку. Подписанного индивидуального задания не будет. Это не блокер. ТЗ, технические требования, КД и РПЗ формируются самостоятельно по методикам МАИ и ЕСКД.

В пособиях 1998/2007 годов ориентир РПЗ — 25–30 страниц А4. Для графической части есть различие форматов и объёма: 1998 — ориентир 2–2,5 листа А1 и не менее 4–5 документов из перечня, 2007 — комплект документов на А4, состав определяет руководитель. Для условного проекта принять цельный полный набор КД и обосновать его, не выдавая за указание преподавателя.

Основная матрица — requirements/verification_matrix.md. Не создавать конкурирующую матрицу. Числовую рубрику оценки не выдумывать.
