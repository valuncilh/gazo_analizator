# МАИ 1998 — Основы конструирования и технологии РЭС

Источник: учебное пособие МАИ для курсового проектирования, 1998, §1.1–1.4, печатные страницы 3–6.

Цель: показать систематизацию знаний, практические навыки конструирования и технологии РЭС, работу с НТД/литературой и разработку КД/ТД.

Исходное задание обычно задаёт назначение, функциональные и материальные показатели, условия эксплуатации/производства. По нему студент разрабатывает ТЗ. В текущем проекте постановка условная, подписанного индивидуального бланка не будет. Самостоятельное ТЗ не имитирует утверждение преподавателя.

Для варианта на ИМС широкого применения вместо конструкции микросборки требуется разработка конструкции ПП. В РПЗ пособие перечисляет задание/исходные данные, введение, ТЗ, анализ ТЗ, конструкторский анализ принципиальной схемы, разработку ПП, функциональной ячейки и изделия, оценочные расчёты качества конструкции, технологический процесс изготовления/сборки, заключение, библиографию и содержание.

Ориентир РПЗ: не более 25–30 страниц А4. Графическая часть содержит принципиальную схему и КД. Возможные документы: топологические чертежи, сборочные чертежи узлов, чертёж ПП, сборочный чертёж функциональной ячейки, общий вид блока, чертежи деталей, схемы ТП. Указан ориентир 2–2,5 листа А1 и не менее 4–5 документов из перечня. Конкретный комплект задаёт руководитель. Это ориентир издания 1998 года.

Последовательность: ТЗ → анализ ТЗ и источников → конструкция → расчёты соответствия ТЗ → анализ технологии/технологичности → РПЗ и графика → подготовка к защите.

Приёмочные проверки:
- [ ] Самостоятельное проектное ТЗ, разделение требований/допущений.
- [ ] Обоснование конструктивно-технологического варианта.
- [ ] Анализ схемы и ЭКБ.
- [ ] ПП для варианта на ИМС.
- [ ] Конструкция функциональной ячейки и изделия.
- [ ] Оценочные расчёты качества конструкции.
- [ ] Технология изготовления/сборки и технологичность.
- [ ] РПЗ и согласованный полный комплект графических документов.
