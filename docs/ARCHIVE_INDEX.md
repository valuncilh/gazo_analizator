# Архив и исторические материалы

Этот каталог-указатель помогает отличить актуальные документы проекта от материалов ранних итераций. Исторические файлы сохранены для прослеживаемости инженерных решений. Они не удаляются, но не должны использоваться для изготовления текущей реализации без повторной проверки.

## Текущая базовая конфигурация

- Основная электрическая схема: утверждённая E3 с Joy-IT SEN-MQ4-V2.
- Питание: отдельная плата USB-C E4, выдающая +5 В на XS1.
- Звуковой излучатель: кандидат Ningbo Kepo HCM1206X.
- Таймер: кандидат TI NE555P.
- Текущий реестр MPN и footprints: [cad/footprint_selection_2026-11-01.md](../cad/footprint_selection_2026-11-01.md).
- Маршрут проверки актуальных документов: [REVIEW_GUIDE.md](REVIEW_GUIDE.md).

## Исторические SPICE-сценарии

Каталог spice сохраняется как расчётно-исследовательская область. Не каждый тестбенч соответствует текущей E3. Перед использованием конкретного файла проверять его README и SOURCE_NOTES.

Особенно важно:
- тестбенчи с TLV7041-Q1, TLC555/КР1006ВИ1, VT2, R9 или моделью Amperka относятся к прежней архитектуре;
- sweep по коэффициенту передачи VT1 показывает чувствительность модели, а не гарантированный режим физического КТ3102Б;
- vendor-модели и поведенческие модели не доказывают характеристики модуля SEN-MQ4-V2 или полного изделия;
- результаты ngspice являются расчётными данными в пределах описанной модели, а не измерениями собранного устройства.

## Исторические изображения и схемы

В docs/figures/ сохранены рисунки исходной статьи, моделей MQ-4, компаратора, таймера и звукового канала. Некоторые изображения создавались для архитектуры с аналоговым выходом Amperka и компаратором U2. Их нельзя автоматически вставлять в описание текущей E3.

Каждое изображение должно иметь:
1. ссылку на исходный генератор или источник;
2. указание схемной редакции;
3. краткое описание допущений;
4. статус актуальности.

## Правила хранения

- Не удалять исторические исходники ради визуальной чистоты.
- Не переносить файлы между каталогами до проверки ссылок, скриптов и относительных путей.
- Не переименовывать исходные KiCad-файлы, находящиеся под утверждённым тегом.
- В корневой README и REVIEW_GUIDE показывать только актуальные документы и явные ссылки на этот индекс.
- В исторических README добавлять верхний статусный баннер, если документ может быть принят за текущую инструкцию.
