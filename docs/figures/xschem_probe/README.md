# Пробный фрагмент xschem

Фрагмент проверяет делитель, использованный как приближение MQ-4 в рисунке 2. Для сценария чистого воздуха принято `Rs = 88 кОм`, `RL = 20 кОм` и `VCC = 5 В`.

Ожидаемые соединения экспортированного netlist:

- `VCC VCC 0 5`.
- `R_S VCC S 88k`.
- `R_L S 0 20k`.

Ручной расчёт: `US = 5 · 20 / (88 + 20) = 0,9259 В`. Тест сравнивает эти связи с netlist xschem, запускает ngspice и сравнивает узловое напряжение с расчётом. Сгенерированный PNG нужен для визуального сравнения с ручным рисунком 2.

Это только проба инструмента на элементарном фрагменте. Она не подтверждает автоматическую корректность остальных схем и не является преобразованием исходного netlist целиком.
