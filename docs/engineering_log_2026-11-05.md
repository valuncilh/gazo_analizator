# Инженерный журнал — 05.11.2026

## Принятые решения пользователя

1. Максимальный ток A1 Joy-IT SEN-MQ4-V2 — не более 180 мА по документации изготовителя.
2. Уставка тревоги остаётся 1000 ppm. Точность не объявляется подтверждённой без метрологической проверки.
3. Для DA1 принят расчётный верхний предел 150 мА по решению пользователя. Это проектное ограничение, а не паспортный максимум TI NE555P.
4. Ориентация A1 и XS1 на PCB выполнена правильно.
5. Полярность HA1, C1 и C3 на PCB выполнена правильно. Положительный вывод определяется по маркировке «+» на корпусе компонента.
6. Пользователь подтвердил, что ERC и DRC выполнены. Повторно запускать их в текущем цикле не требуется.
7. Тепловой режим уже рассмотрен в РПЗ. Повторный расчёт не требуется.
8. Корпус почти завершён.
9. СБ и ВО требуется выпустить. Спецификацию формировать по фактической PCB/сборке.
10. A4-выдачу отложить на следующий этап.
11. Актуальная ODT-редакция РПЗ находится в OneDrive и будет предоставлена пользователем для синхронизации.

## Токовый бюджет

| Нагрузка | Ток |
|---|---:|
| A1 | 180 мА |
| DA1 | 150 мА |
| HA1 | 40 мА |
| HL1/HL2 | до 31,6 мА |
| R1 | 0,034 мА |
| **Сумма** | **401,634 мА** |

Прежнее целевое ограничение 300 мА не является жёстким. По решению пользователя проектный предел питания допускается увеличить, если расчётная оценка не совпадает с реализацией. Расхождение следует явно отразить в РПЗ.

Предварительный выбор F1 для дальнейшей разработки E4: **T630 mA**, замедленный предохранитель. Окончательный MPN выбирается после проверки времятоковой характеристики, I²t, температурного derating, пускового тока и допустимых токов USB-C источника, разъёма, кабеля и дорожек.

## Сборочная документация

- СБ и ВО выпускать в FreeCAD через TechDraw на основе актуальной 3D-сборки.
- KiCad использовать для Э3 и чертежа ПП.
- A4-выдачу выполнять отдельным последующим этапом.
