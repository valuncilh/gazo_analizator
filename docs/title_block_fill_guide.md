# Инструкция по заполнению штампа и основной надписи

Основание: ГОСТ Р 2.104-2023 и анализ ранее загруженной РПЗ. Статус: рабочая инструкция. Точная кафедральная форма и обозначение требуют подтверждения.

## Выбор формы

ГОСТ Р 2.104-2023 задаёт основные надписи и дополнительные графы. Для графических документов ориентиром служат форма 1 на первом листе и форма 2а на последующих листах. Для текстовых документов предусмотрены формы 2, 2а и 2б. Официальная карточка: https://protect.gost.ru/gost/details/69d422a2-3c0e-4561-a521-0c99f9cf4417. Текст стандарта с изображениями форм: https://base.garant.ru/408164565/.

В доступной старой кафедральной РПЗ используется штамп, визуально отличающийся от стандартного набора форм 2/2а. Не следует автоматически менять его без подтверждения, что в кафедре действует именно новая форма.

## Поля

| Поле | Рабочее заполнение | Правило |
|---|---|---|
| Наименование изделия | Бытовой сигнализатор утечки газа | Использовать одинаково во всех документах. |
| Дисциплина | Основы конструирования и технологии производства РЭС | Как в ранее загруженной РПЗ. |
| Факультет | Радиоэлектроника летательных аппаратов | Проверить актуальное официальное наименование. |
| Кафедра | В прежней редакции встречается кафедра радиоэлектронных систем и устройств | Подтвердить текущее название. |
| Вид документа | Пояснительная записка, схема электрическая принципиальная, перечень элементов и т. п. | Указывать реальный вид документа. |
| Разработал | Пусто до указания ФИО | Не подставлять имя без согласования. |
| Проверил | Пусто | ФИО и подпись руководителя не выдумывать. |
| Н.контр. и Утв. | Пусто до подтверждения | Заполнять только если кафедра требует такие графы. |
| Группа | Пусто | Получить точное значение из задания. |
| Подписи и даты | Пусто | Дата генерации файла не является датой подписи. |
| Литера | Не назначать самостоятельно | Уточнить у руководителя. |
| Масштаб | Только для чертежей | Заполнять после выбора масштаба в CAD. |
| Лист / Листов | После финальной верстки | Использовать фактическое число листов. |
| Масса | По назначению соответствующего графического КД | Не переносить массу из концептуальной модели без проверки. |
| Обозначение | Пока предварительное | Утвердить базовый код и коды документов. |

## Проблема шифра

В доступной РПЗ встречаются МАИР.РЭС.001ПЗ и МАИР.ХРЭС.001. Их нельзя считать равнозначными без пояснения руководителя. Не выпускать финальные чертежи с предположительным кодом.

## Последовательность заполнения

1. Получить исходный бланк индивидуального задания и утверждённый кафедральный штамп.
2. Утвердить базовое обозначение изделия.
3. Согласовать коды Э3, ПЭ3, ПП, СБ, ВО и ПЗ.
4. Свести название изделия и обозначения во всех листах, оглавлении и реестре.
5. После финального CAD-экспорта заполнить масштаб, листы, их общее количество и массу там, где нужно.
6. Оставить подписи, ФИО утверждающих и даты пустыми до фактического подписания.
7. После каждого окончательного экспорта проверить все страницы на обрезание, перекрытия и повреждение рамки.

Отдельный подписанный бланк задания не обнаружен в доступной библиотеке. Для финального ТЗ необходим оригинал или подтверждение руководителя, что текущего проектного ТЗ достаточно.
