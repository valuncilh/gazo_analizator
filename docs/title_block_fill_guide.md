# Инструкция по заполнению титульного листа, форм ПЗ и основной надписи

**Дата нормативной сверки:** 30.10.2026.  
**Статус:** рабочая инструкция с объединёнными сведениями о титульном листе, формах ПЗ и основной надписи. Титульный лист и основная надпись не утверждены. Точный кафедральный шаблон, реквизиты и обозначение проекта требуют подтверждения.

## 1. Не смешивать три элемента оформления

### Титульный лист курсового проекта

Титульный лист оформляется по актуальному шаблону МАИ и требованиям руководителя. Он не является автоматически основной надписью по ГОСТ Р 2.104-2023 и не заменяется формами 9/9а. До получения шаблона не следует дорисовывать рамку, графы, подписи или утверждающие реквизиты по собственному предположению.

### Текст пояснительной записки

Для текста пояснительной записки применяются формы 9 и 9а приложения А ГОСТ Р 2.106-2019 в редакции с изменением № 1. Правило относится именно к тексту ПЗ. Его нельзя заменять общими формами текстовых документов из ГОСТ Р 2.104-2023.

### Основная надпись и дополнительные графы

Основную надпись и дополнительные графы выполняют по ГОСТ Р 2.104-2023 для соответствующего вида конструкторского документа. Для графических документов ГОСТ Р 2.104-2023 предусматривает форму 1 на первом листе и форму 2а на последующих. По приложению Б, Б.5, листы A4 выполняются только в книжной ориентации, основная надпись размещается вдоль короткой стороны. Для текстовых документов стандарт содержит формы 2, 2а и 2б, однако для пояснительной записки специальное правило ГОСТ Р 2.106-2019 устанавливает формы 9/9а. Для схем, таблиц и графического материала в составе ПЗ учитываются пункт 4.10.1 ГОСТ Р 2.106-2019 и форматы по ГОСТ 2.301. Основная надпись графического листа не является титульным листом курсового проекта.

- ГОСТ Р 2.104-2023: https://protect.gost.ru/gost/details/69d422a2-3c0e-4561-a521-0c99f9cf4417.
- ГОСТ Р 2.106-2019: https://protect.gost.ru/gost/details/a65c2b20-2cfb-4326-abd5-3aad62db747c.
- Изменение № 1 к ГОСТ Р 2.106-2019: https://protect.gost.ru/gost/changesdetails/bd5a6af7-d1c4-4fd6-98fc-4d6bf90a3103.

## 2. Данные титульного листа для согласования

| Поле | Рабочее значение | Статус |
|---|---|---|
| Учебное заведение | Московский авиационный институт (национальный исследовательский университет) | Проверить точное написание по шаблону МАИ. |
| Факультет | «Радиоэлектроника летательных аппаратов» | Проверить актуальное официальное название. |
| Кафедра | В прежней редакции встречается «Кафедра радиоэлектронных систем и устройств» | Подтвердить актуальное название. |
| Дисциплина | «Основы конструирования и технологии производства РЭС» | Рабочее значение из ранее загруженной РПЗ. |
| Тема / изделие | «Бытовой сигнализатор утечки газа» | Использовать единообразно после утверждения формулировки. |
| Вид документа | «Расчётно-пояснительная записка к курсовому проекту» | Сверить с кафедральным шаблоном. |
| ФИО студента | Не заполнено | Заполняет пользователь. |
| Группа | Не заполнено | Заполняет пользователь по заданию. |
| Руководитель | Не заполнено | Уточнить официальное написание должности и ФИО. |
| Город и год | Не заполнено | Сверить с шаблоном и фактической датой сдачи. |

## 3. Реквизиты основной надписи

| Поле | Правило заполнения |
|---|---|
| Обозначение документа | Не назначать до утверждения базового обозначения изделия и кода документа. |
| Наименование документа | Указывать фактический вид документа по принятой системе обозначений. |
| Разработал | Оставить пустым до подтверждения ФИО и фактического подписания. |
| Проверил | Оставить пустым до фактического назначения и подписания руководителем. |
| Н.контр. и Утв. | Заполнять только если такие графы предусмотрены формой и требуются кафедрой. |
| Подписи и даты | Не имитировать. Заполнять только после фактического подписания. |
| Литера | Не назначать самостоятельно. Уточнить у руководителя. |
| Масштаб | Заполнять только для соответствующего чертежа после фиксации масштаба. |
| Лист / Листов | Заполнять после окончательной верстки и утверждения состава листов. |
| Масса | Заполнять только в тех документах, где графа предусмотрена, после проверки фактической конструкции. |

Для текстовой части ПЗ применять формы 9/9а. Нельзя переносить в неё произвольный кафедральный штамп вместо формы, установленной ГОСТ Р 2.106-2019, без согласованного основания. Для чертежей и других графических КД форму основной надписи выбирать по ГОСТ Р 2.104-2023.

## 4. Неразрешённый конфликт обозначения

В старых материалах встречаются обозначения `МАИР.РЭС.001ПЗ` и `МАИР.ХРЭС.001`. Не считать их эквивалентными и не выбирать один из вариантов без ответа руководителя. До согласования все обозначения остаются предварительными.

## 5. Порядок окончательного заполнения

1. Получить исходный бланк индивидуального задания и актуальный титульный шаблон кафедры.
2. Подтвердить официальные наименования факультета и кафедры.
3. Утвердить базовое обозначение изделия и систему кодов документов.
4. Согласовать коды Э3, ПЭ3, ПП, СБ, ВО и ПЗ.
5. Для текста ПЗ применить формы 9/9а по ГОСТ Р 2.106-2019 с изменением № 1.
6. Для графических документов выбрать основную надпись по ГОСТ Р 2.104-2023.
7. Свести название изделия и обозначения во всех листах, оглавлении и реестре.
8. После финального CAD-экспорта заполнить масштаб, листы, общее число листов и массу там, где это предусмотрено.
9. Оставить подписи, ФИО утверждающих и даты пустыми до фактического подписания.
10. После каждого окончательного экспорта проверить все страницы на обрезание, перекрытия и повреждение рамки.

Отдельный подписанный бланк индивидуального задания не обнаружен в доступной библиотеке. Для финального ТЗ необходим оригинал или подтверждение руководителя, что текущего проектного ТЗ достаточно.
