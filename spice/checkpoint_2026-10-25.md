## Результат первого реального прогона

GitHub Actions установил ngspice 42 и выполнил netlist. Сам анализ завершился успешно, временные данные созданы, скрипт построения графиков прошёл синтаксическую проверку Python.

Из первого лога:

| Параметр | Результат |
|---|---:|
| Количество строк переходного расчёта | 30 113 |
| Время подъёма RESET | 0,5206997 с |
| Первый фронт OUT | 0,5207004 с |
| Первый измеренный интервал OUT | 0,1114123 с |
| Установившийся период OUT по следующему фронтам | Около 0,0802 с |

Первый интервал 111,4 мс — это пусковое поведение, когда C1 заряжается почти с нуля до верхнего порога. После установления циклического режима интервал между фронтами близок к 80,2 мс, что согласуется с ручной оценкой около 80,1 мс для R4 = R5 = 8,2 кОм и C1 = 4,7 мкФ.

Пиковый ток относится только к смоделированной электронной цепи. Реальный ток платы A1 и её нагревателя не включён и не может быть заменён этим результатом.

## Ошибка, выявленная первым запуском

Расчёт ngspice прошёл. Построитель графиков завершился ошибкой распаковки матрицы NumPy, потому что двумерный массив был распакован как последовательность столбцов без индексирования оси. Строка исправлена на явное извлечение каждого столбца. Исправление сохранено в `spice/plot_results.py`. Следующий прогон GitHub Actions проверит создание изображения.

## Границы модели

- `VSENSE` — синтетический сигнал 0,30–4,50 В. Он не моделирует сопротивление чувствительного элемента и не переводит напряжение в ppm.
- U2 — поведенческий компаратор с открытым стоком и приближённым гистерезисом, а не официальная макромодель TLV7041-Q1.
- VT1 и VT2 используют общий NPN proxy. Это не подтверждённая модель КТ3102ГМ.
- DA1 — идеализированный 555-подобный таймер на управляемых ключах, а не модель КР1006ВИ1.
- HA1 заменён резистивной нагрузкой около 167 Ом для расчётного тока порядка 30 мА. Акустика и электромеханические переходы отсутствуют.
- Источник питания идеальный 5 В. Просадка адаптера и проводов не моделируются.

## Следующие действия

1. Подтвердить успешное создание графиков исправленным скриптом в последующем workflow.
2. Провести отдельный прогон C1 = 47 мкФ и проверить установившийся период около 0,80 с. Не изменять номинал проектной схемы без сверки исходника.
3. Скачать и интегрировать официальную PSpice-модель TLV7041-Q1, если она совместима с выбранным симулятором и условиями использования. Страница производителя: https://www.ti.com/product/TLV7041-Q1.
4. Найти или подготовить проверенные модели конкретных транзисторов и таймера.
5. Добавить проверенный сценарий потребления A1 отдельно от логики цепочки. Только затем выполнять сравнение с пределом 300 мА.
6. По физическому макету измерить S при известных концентрациях CH4, уровни RESET и DA1 при нагрузке и ток холодного запуска.

Результаты первого прогона подтверждают, что netlist запускается, но пока подтверждают только функциональную поведенческую модель. Они не доказывают точность порога 1000 ppm, предельные уровни реальных компонентов и безопасность устройства.
