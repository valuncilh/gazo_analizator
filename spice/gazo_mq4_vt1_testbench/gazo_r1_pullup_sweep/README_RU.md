# GAZO.001 — второй SPICE-этап: чувствительность R1 для DOUT с открытым коллектором

## Для чего нужен тест

Первый прогон показал, что в упрощённой модели при `BF=50` и отпущенном open-collector DOUT напряжение `RESET` поднимается примерно до 2.498 В. Для NE555 это уже снятый RESET, а не уверенный низкий уровень. При `BF=200/500` модель давала около 0.16 В.

Этот тест проверяет, как результат зависит от подтягивающего R1 при неизменных `R2=13 кОм`, `R3=2 кОм`, `VCC=5 В`.

## Что проверяется

Для каждого `BF=50/200/500` моделируются два независимых набора:

1. `OC RELEASED` — выход датчика разомкнут, подтяжка только через исследуемый R1 из схемы.
2. `OC LOW` — выход датчика условно замкнут на землю через 10 Ом. Дополнительно измеряется ток, который должен поглотить выход DOUT через pull-up R1.

Проверяемые значения R1: 160 кОм, 100 кОм, 82 кОм, 68 кОм, 56 кОм, 47 кОм, 33 кОм, 22 кОм, 10 кОм, 6,8 кОм, 4,7 кОм и 3,3 кОм.

Это исследовательская сетка, а не предложенные номиналы для замены.

## Как интерпретировать

В сценарии `OC RELEASED` сравниваем `v(reset_...)` с характеристикой RESET NE555 из datasheet TI. При VCC=5 В таблица TI задаёт уровень RESET min=0,3 В, typ=0,7 В, max=1,0 В при опубликованных условиях измерения. RESET ниже 0,3 В — уверенный активный низкий уровень с учётом опубликованного диапазона. RESET выше 1,0 В — сброс снят, таймер разрешён. Зона 0,3–1,0 В требует учёта разброса порога конкретной микросхемы.

В сценарии `OC LOW` поле `ipu_low` — приближённый ток через внешний R1, который выход датчика должен поглотить. Сравним его с допустимым током DOUT, когда найдём подтверждённый параметр Joy-IT.

## Ограничения

- BF=50/200/500 — искусственные точки чувствительности модели при `TEMP=27 °C`; температура не моделируется изменением BF автоматически.
- КТ3102Б остаётся оценочной моделью, не заводской SPICE-моделью конкретной партии.
- Открытый коллектор Joy-IT SEN-MQ4-V2 не подтверждён паспортом. Это гипотеза, проверяемая отдельно.
- Выход DOUT имеет условный sink 10 Ом в активном состоянии. Это не паспортный параметр модуля.
- RESET NE555 в схеме представлен высокоомным входом. Нелинейная входная модель самой NE555 в этот этап не включена.
- Не менять R1 в реальном устройстве на основании этого прогона. Сначала требуется подтверждение топологии DOUT и допустимого тока его выхода.
