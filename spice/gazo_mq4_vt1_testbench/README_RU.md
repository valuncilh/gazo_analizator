# GAZO.001 — первый SPICE-набор: DOUT → R2 → КТ3102Б → RESET NE555

## Назначение

Этот набор проверяет входную цепь окончательной схемы `gazo_analizator_E3_GOST_itog.kicad_sch` по экспортированным соединениям KiCad XML:

- `R1 = 160 кОм`: VCC → DOUT;
- `R2 = 13 кОм`: DOUT → база VT1;
- `VT1 = КТ3102Б`: NPN, эмиттер → GND, коллектор → RESET DA1;
- `R3 = 2 кОм`: VCC → RESET DA1.

Состав ветви проверяется по точному netlist, а не по старым моделям Amperka/TLV7041/TLC555 из архивного проекта.

## Что моделируется

`run_tests.py` создаёт три варианта одного и того же DC testbench:

| Файл | BF модели VT1 | Назначение |
|---|---:|---|
| `matrix_beta_50.cir` | 50 | нижняя оценка h21э при −40 °C |
| `matrix_beta_200.cir` | 200 | нижняя граница при +25 °C / +85 °C |
| `matrix_beta_500.cir` | 500 | верхняя граница для выбранной группы |

В каждом прогоне параллельно рассматриваются четыре независимых схемы входа:

1. **PP LOW** — push-pull выход DOUT удерживает 0 В через условные 50 Ом.
2. **PP HIGH** — push-pull выход DOUT удерживает 5 В через условные 50 Ом.
3. **OC LOW** — открытый коллектор замкнут на GND через условные 10 Ом.
4. **OC RELEASED** — выходной транзистор датчика отпущен, а подтяжку обеспечивает только R1=160 кОм из утверждённой схемы. Внутренняя подтяжка модуля не предполагается.

Указанные 50 Ом и 10 Ом — тестовые допущения для имитации низкоомного логического выхода/открытого коллектора. Они не взяты из паспорта Joy-IT.

## Как запускать в CachyOS

Проверь наличие ngspice:

```fish
ngspice --version
```

Если команда не найдена:

```fish
sudo pacman -S ngspice
```

Распакуй архив, перейди в каталог `gazo_mq4_vt1_testbench` и запусти:

```fish
python3 run_tests.py
```

Скрипт создаст три `.cir`-файла и сохранит логи в `results/`.

## Какие величины смотреть

Для каждого из четырёх сценариев в лог записываются:

- `v(dout_...)` — уровень на выводе DOUT;
- `v(base_...)` — напряжение базы VT1;
- `v(reset_...)` — напряжение на выводе RESET NE555;
- `ib_...` — ток базы, рассчитанный по падению на R2;
- `ic_...` — ток коллектора, рассчитанный по падению на R3.

Ориентиры для первичной интерпретации, не замена порогам конкретной ревизии NE555:

- RESET около 0…0,4 В — уверенный низкий уровень;
- RESET около 4…5 В — уверенный высокий уровень;
- промежуточный уровень — не считать однозначным логическим состоянием, требуется сверка с datasheet NE555 и измерение.

Ожидаемая логика самой схемы: VT1 открыт → RESET низкий → генератор NE555 запрещён; VT1 закрыт → RESET подтянут вверх через R3 → генератор разрешён.

## Ограничения модели КТ3102Б

В открытых справочных данных для КТ3102Б приводится h21э = 200…500 при +25 °C и нижняя граница 50 при −40 °C в указанном режиме измерения (UКБ=5 В, IЭ=2 мА). Для оценки чувствительности используются BF=50/200/500. BF=50 — стресс-значение, соответствующее нижнему справочному h21э при −40 °C, но сам прогон SPICE не моделирует температуру: температура модели остаётся стандартной, меняется только BF.

Вывод RESET моделируется как высокоомный вход NE555. Внутренние пороги и динамика NE555 в этом первом тесте пока не моделируются.

Это **не заводская SPICE-модель КТ3102Б**. Значение BF привязано к указанному диапазону h21э, а IS, VAF, IKF, ёмкости и паразитные сопротивления модели заданы как приближения. Поэтому DC-прогон помогает найти слабые места и сравнить состояния, но не доказывает точные параметры конкретного экземпляра.

## Почему DOUT не привязан к ppm в этом тесте

Паспорт Joy-IT SEN-MQ4-V2 подтверждает питание 5 В, AOUT 0…5 В и цифровые уровни DOUT 0/5 В с регулируемым порогом. Но в опубликованном datasheet не указаны полярность тревоги, тип выходного каскада (push-pull/open-collector), наличие внутренней подтяжки и допустимый ток DOUT.

Поэтому матрица честно проверяет оба логических уровня и два варианта выходного каскада, не назначая им семантику «норма/тревога».

## Отдельная модель аналогового сенсорного делителя

`mq4_ratio_transfer.cir` — отдельная исследовательская модель чувствительного элемента:

- `RL=1,5 кОм` взято из формулы на странице 3 datasheet Joy-IT V2;
- `Rs=R0·(Rs/R0)`;
- `R0=3,86018237 кОм` — только пример калибровки из README библиотеки MQSensorsLib, НЕ измеренное значение Joy-IT V2;
- отношения 4,4 / 1,0 / 0,6 — точки для анализа отношения Rs/R0, а не подтверждённые пороги 60/1000/4400 ppm именно этого модуля.

Библиотека MQSensorsLib — программная библиотека для пересчёта аналогового значения и Rs/R0 в оценку ppm. Она не является SPICE-моделью платы SEN-MQ4-V2 и не описывает её DOUT-компаратор.

## Что прислать после запуска

Прикрепи все четыре файла из `results/`:

- `matrix_beta_50.log`
- `matrix_beta_200.log`
- `matrix_beta_500.log`
- `mq4_ratio_transfer.log`

Если команда завершилась ошибкой, приложи полный вывод терминала и созданные логи. Схему и номиналы пока не менять.

## Источники и границы применимости

1. Joy-IT, `SEN-MQ4-V2_Datasheet-EN_2026-01-15.pdf`, 15.01.2026. Характеристики платы, 5 В, AOUT 0…5 В, DOUT 0/5 В, диапазон около 300…10000 ppm, RL=1,5 кОм в формуле сенсорного делителя. Паспорт не раскрывает схему и тип выходного каскада DOUT.
2. `README_SEN_MQ4_V2_PINOUT.md` из материалов проекта. Распиновка нижней гребёнки 2,54 мм: 1=VCC, 2=DOUT, 3=AOUT, 4=GND.
3. MQSensorsLib: https://github.com/miguel5612/MQSensorsLib — программная аппроксимация и алгоритм калибровки по аналоговому выходу.
4. КТ3102, справочные данные: https://m-elek.h1n.ru/elektronic/help/vt/vtb-rus/vtb-rus-npn/kt3102.html и учебный документ ТУСУР: https://edu.tusur.ru/publications/6776/download.

Все результаты этого комплекта — расчётная проверка ограниченных подмоделей. Это не подтверждение точности обнаружения CH4, не калибровка 1000 ppm и не проверка безопасности газоанализатора.
