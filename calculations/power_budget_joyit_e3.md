# Токовый бюджет утверждённой E3 с Joy-IT SEN-MQ4-V2

**Актуальность:** 02.11.2026  
**Статус:** расчётная оценка с ограниченными паспортными данными. Полный worst-case ток изделия и выбор ограничителя E4 остаются **BLOCKED/TBC**.  
**Объём:** расчёты по документации и утверждённой топологии. Физическое изготовление и измерения не выполняются.

## 1. База расчёта

Расчёт относится только к неизменяемой утверждённой E3 с Joy-IT SEN-MQ4-V2. Архивные Amperka AMP-B052, U2/TLV7041-Q1, VT2/R9 и другие старые цепи не используются.

| Параметр | Принято | Основание |
|---|---:|---|
| Номинальное питание | 5,0 В DC | Условия проекта и паспорт Joy-IT |
| Диапазон для расчётов | 4,9…5,1 В | Проектное допущение ±0,1 В |
| Целевое ограничение полного тока | 300 мА | Требование проекта, ещё не доказано |
| Температура среды | +10…+35 °C | Утверждено пользователем 02.11.2026 |
| Относительная влажность | 20…80 %, без конденсации | Утверждено пользователем 02.11.2026 |
| A1 | Joy-IT SEN-MQ4-V2 | Выбранная модель; max total current в доступном паспорте не задан |
| DA1 | TI NE555P, PDIP-8 | Кандидат физического исполнения, 0…+70 °C |
| HA1 | Ningbo Kepo HCM1206X OEM2690R | Model-specific drawing, но есть конфликт с общей спецификацией HCM12X |

## 2. Оценка отдельных нагрузок

### 2.1 Сенсор A1

Паспорт SEN-MQ4-V2 указывает питание 5 В, регулируемые аналоговый и цифровой выходы и время прогрева 10…15 минут. Гарантированный максимальный полный ток всей платы A1 и максимальная мощность нагревателя в доступной документации не заданы.

Вводим неизвестные параметры:

[
I_{A1,max}, qquad P_{A1,max}
]

Их нельзя заменить типовым значением из карточки другой платы MQ-4. Поэтому полный ток A1 остаётся TBC. Если изготовитель не публикует гарантированный верхний предел для выбранной ревизии, доказать соблюдение общего лимита 300 мА только по имеющейся документации невозможно.

### 2.2 Звуковой излучатель HA1

Drawing Ningbo Kepo HCM1206X OEM2690R задаёт 6 В nominal, рабочий диапазон 4…8 В, до 40 мА при 6 В, SPL 88 дБ/10 см, корпус Ø12 × 9,5 мм и шаг выводов 7,6 ±0,2 мм. Общая спецификация семейства HCM12X расходится и приводит 30 мА при 6 В, 4…7 В. До окончательного уточнения варианта сохраняем 40 мА как консервативное значение тока и пересечение 4…7 В как консервативное рабочее напряжение.

Для расчётной электрической оболочки при 5,1 В:

[
P_{HA1,mathrm{env}} = 5.1 cdot 0.040 = 0.204 	ext{Вт}
]

Это произведение верхнего проектного напряжения на паспортную токовую оценку. Оно не является паспортной мощностью при 5,1 В и не описывает среднюю мощность импульсного режима E3. Физическая полярность вывода HA1.1 остаётся TBC по доступному чертежу.

### 2.3 DA1 — TI NE555P

TI NE555 datasheet Rev. K, таблица 5.5, при VCC=5 В без нагрузки указывает:
- output low: 3 мА min, 6 мА typ;
- output high: 2 мА min, 5 мА typ.

Максимум для стандартного NE555 в этих строках не нормирован. Поэтому 6 мА можно использовать только как типовую оценку сценария, но не как гарантированный максимум для worst-case бюджета.

Для полного бюджета оставляем:

[
I_{DA1,max} = mathrm{TBC}
]

Не переносить максимум от CMOS- или малопотребляющего варианта таймера на NE555P.

### 2.4 HL1 и HL2

Для предварительной верхней оценки используются R6=R7=220 Ом ±5 %, Umax=5,1 В и Vf,min=1,8 В. Это консервативная резисторная оценка, а не точный режим всей схемы. Для каждого независимого резисторного канала:

[
R_{min}=220cdot0.95=209 Omega
]

[
I_{mathrm{LED,env}}=rac{5.1-1.8}{209}=15.79 	ext{мА}
]

Для двух каналов условная сумма составляет:

[
I_{mathrm{LED,total,env}}le31.6 	ext{мА}
]

Верхняя оценка мощности каждого резистора:

[
P_{R,mathrm{env}}=rac{(5.1-1.8)^2}{209}=0.0521 	ext{Вт}
]

Фактический ток HL1 зависит от UOH DA1 при совместной нагрузке. Точная ветвь HL2 связана с HA1/SA1/R7/C3 по утверждённому netlist, поэтому считать 31,6 мА точным потреблением реальной топологии нельзя. Это консервативная граница для первичной оценки резисторных каналов.

Это оценка нагрузки цепи DOUT→R2→VT1. Допустимый ток DOUT изготовителем не нормирован в доступном паспорте. Ток не прибавляется повторно к полному питанию: он относится к внутреннему балансу сенсорного модуля и внешней цепи, а точная реализация выходного каскада A1 не документирована.

## 3. Сводная расчётная граница

Составим только частичную сумму известных внешних нагрузок, для которых имеются верхние расчётные оценки:

| Нагрузка | Верхняя оценка | Ограничение |
|---|---:|---|
| HA1 | 40 мА | По model-specific drawing при 6 В, не измерено при 5 В |
| HL1/HL2 | до 31,6 мА | Условная независимая резисторная оболочка |
| R1 | 0,034 мА | По Umax и Rmin |
| DA1 | TBC | TI не задаёт max в указанной строке |
| A1 | TBC | Max total current не указан |

Частичная сумма только трёх строк с заданными оценками:

[
I_{mathrm{known,partial}}=40+31.6+0.034=71.634 	ext{мА}
]

Полная оценка должна иметь вид:

[
I_{mathrm{total}} =
I_{A1} + I_{DA1} + I_{HA1} + I_{HL1/HL2} + I_{mathrm{other}}
]

Поскольку (I_{A1,max}) и (I_{DA1,max}) не заданы гарантированными значениями, выражение не даёт доказанного численного upper bound для изделия.

Для ориентира, если использовать типовое потребление DA1 6 мА и приведённую оболочку внешних нагрузок, получится условный сценарий около 77,6 мА вне A1. Это не worst-case и не PASS.

Если временно принять условие, что внешняя нагрузка равна 77,6 мА, то остаток до 300 мА составил бы:

[
I_{A1,mathrm{budget,conditional}}=300-77.6=222.4 	ext{мА}
]

Это только условное ограничение для анализа. Его нельзя трактовать как гарантированный допустимый ток A1 и нельзя использовать для окончательного выбора eFuse/PTC.

## 4. Решение для E4

1. Не назначать F1 только на основании типового тока A1 или желаемого лимита 300 мА.
2. В качестве расчётной модели учитывать гарантированные максимумы внешних MPN и отдельно неопределённые (I_{A1,max}), (I_{DA1,max}).
3. Проверить возможности USB Type-C sink без PD: нельзя предполагать доступность 1,5 А или 3 А без соответствующей индикации источника по CC.
4. Выбрать TVS по документированным параметрам VBUS и критериям защиты, отдельно от токового ограничителя.
5. Если изготовитель не предоставляет максимальный полный ток A1, оставить токовый бюджет 300 мА и выбор F1 в статусе BLOCKED/TBC. Это ограничение документального проекта, а не задача на физические измерения.
